# Integer-cent JSON API design

Status: committed

## Goal and public interface

Expose `invoice_totals.json_output.totals_to_json(totals: Mapping[tuple[str, str], int]) -> str` for callers with already-computed totals. Each exact `(customer, currency)` key identifies one group and its value is integer cents, including negative and zero amounts. This API works without CSV input, aggregation, or the batch API. Python 3.12+ and the standard library remain the only requirements.

Return a JSON array sorted by original customer and then currency using Python string order. Each object has exactly `customer`, `currency`, `total` fields in that order; `total` is a fixed two-place string. Use `json.dumps` with `ensure_ascii=False` and `separators=(",", ":")`, without a trailing newline. Empty input returns exactly `[]`. For `{("示例客户", "CNY"): 125}`, return exactly `[{"customer":"示例客户","currency":"CNY","total":"1.25"}]`.

## Options and decision

Choose a self-contained validation-and-serialization module using integer arithmetic and the standard JSON encoder. Reusing report helpers would couple serialization to CSV ingestion; extracting common helpers would expand the agreed write bounds. Formatting with float or Decimal would introduce avoidable precision or context behavior. Small local integer formatting is the clearest independent approach.

Validate `collections.abc.Mapping` before reading items. Validate every key as a tuple of exactly two strings, and require both strings to contain a non-whitespace character using `strip()` only for this check. Retain their exact original spelling, Unicode and whitespace. Require `type(cents) is int`: booleans, integer subclasses, floats, Decimal values and strings raise `TypeError`, without coercion. Invalid mapping/key types or shapes also raise `TypeError`; blank customer or currency strings raise `ValueError`. Exception text identifies the invalid component; exact wording is not a public contract.

Copy validated entries into local storage, then sort and serialize them. Nothing is returned until all validation and encoding succeeds. The ordinary mapping contract applies; concurrent caller mutation and malicious custom mappings are not supported. Do not mutate caller data or merge groups. Use sign and `divmod(abs(cents), 100)` for amounts. To preserve arbitrarily large ordinary integers under Python's default decimal-digit conversion limit, convert a large whole part through bounded base-1,000,000,000 chunks and join zero-padded chunks; do not change the process-wide digit limit. Zero always renders `0.00`.
